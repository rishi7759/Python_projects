
### Python Random Number & OTP Generator

A simple Python project that demonstrates how to generate **4-digit One-Time Passwords (OTPs)** and work with random numbers using Python's built-in modules. 

### 🚀 Features

* Generates a secure, randomized **4-digit numeric OTP**.
* Explains the correction of string concatenation loops in Python.
* Includes both traditional math-based and cleaner Pythonic implementations.

### 🛠️ Code Implementations

### 1. Basic Loop Method

This approach uses math.floor() along with random.random() inside a loop to dynamically build a string digit by digit.
