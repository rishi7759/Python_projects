# 📝 To-Do List — Python

A simple and beginner-friendly **To-Do List application built with Python**.
This project helps users manage their daily tasks by adding, viewing, completing, and deleting tasks.

## 🚀 Features

* ➕ Add new tasks
* 📋 View all tasks
* ✅ Mark tasks as completed
* ❌ Delete tasks
* 💾 Store tasks using file handling
* 🔄 Simple command-line interface
* 🐍 Built completely with Python

## 🛠️ Technologies Used

* **Python 3**
* Lists
* Functions
* Loops
* Conditional Statements
* File Handling

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/to-do-list-python.git
```

### 2. Open the project folder

```bash
cd to-do-list-python
```

### 3. Run the program

```bash
python todo.py
```
